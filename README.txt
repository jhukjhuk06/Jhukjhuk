JHUK JHUK HOLIDAYS Website — Packaged Project

READY-TO-RUN STRUCTURE

index.html
assets/
  css/
    style.css
  js/
    script.js
  images/
    jhuk-jhuk-logo.png (or .jpg)
  IMAGE_SOURCES.txt

HOW TO RUN
1. Extract the ZIP.
2. Keep the complete folder structure together.
3. Open index.html in Chrome or Edge.

IMPORTANT
- Company logo is stored locally inside assets/images.
- CSS and JavaScript are now separate local asset files and linked to index.html.
- Current destination photography is referenced from Unsplash and therefore needs an internet connection to display.
- IMAGE_SOURCES.txt contains the current external image references.

Baseline: JHUK JHUK HOLIDAYS Website v21 Destination Explorer.
